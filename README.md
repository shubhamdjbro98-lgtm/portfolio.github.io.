# Shubham Portfolio — Starter Project

## What is included
- Responsive one-page portfolio
- Interactive desktop hero with left / center / right cursor zones
- Mobile-friendly center interaction
- About, Skills, Projects, Journey and Contact sections
- No framework required

## Run it
1. Open this folder in VS Code.
2. Install the "Live Server" VS Code extension (optional but recommended).
3. Right-click `index.html` → "Open with Live Server".
4. Move the mouse across the hero to test the interaction.

## IMPORTANT: replace before publishing
1. Replace `your.email@gmail.com` in `index.html`.
2. Replace LinkedIn and GitHub links with your profiles.
3. Add your real project links.
4. Replace the CSS character with your AI-generated frame animation when ready.

## Adding your real character frames
Create:
assets/frames/working.webp
assets/frames/look-left.webp
assets/frames/look-right.webp
assets/frames/greeting.webp
assets/frames/wave.webp
assets/frames/point-down.webp

Then the hero can be upgraded from CSS illustration → frame sequence.

The supplied reference guide recommends:
Video → Frames → Interactive Website Animation.
It also recommends a fixed camera, consistent character/clothes/laptop/lighting, no cuts or camera movement, and separate left/right/center interactions.
